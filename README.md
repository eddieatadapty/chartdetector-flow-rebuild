# ChartDetector Growth Audit

**Live → https://eddieatadapty.github.io/chartdetector-flow-rebuild/**

Five ideas to turn more ChartDetector users into subscribers, each built into a clickable version of ChartDetector's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Use the three answers you collect | +10–20% CR to purchase |
| 02 | Let ChartDetector read a chart before you ask for money | +10–25% CR to purchase |
| 03 | Earn trust while the AI works | +3–8% CR to purchase |
| 04 | Make the yearly plan the obvious choice | +10–20% ARPU |
| 05 | Catch the people who close the paywall | +5–10% CR to purchase |

Every price, rating and feature comes from ChartDetector's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for ChartDetector AI. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
